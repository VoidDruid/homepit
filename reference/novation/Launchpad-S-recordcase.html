Product description Novation Launchpad S

When triggering clips and mixing in Ableton Live, the focus is on direct control via the grid rather than the mouse. The Novation Launchpad S is a USB MIDI controller with 64 multi-colour backlit pads for controlling clips, scenes and other functions. In Ableton Live, the colours indicate, among other things, whether a clip is ready, playing or being recorded.

In Session mode, you can start individual clips or entire scenes using the side buttons. The navigation buttons let you move the controllable area of the 8×8 grid through tracks and scenes. The Session Overview displays larger live sets in blocks, so you can find the section you want directly on the device, even in extensive projects.

Mixer mode assigns important Live functions to the grid, including track volume, panning and Sends A and B. Other pads mute tracks, stop clips, activate Solo or enable recording. On the Volume, Pan and Send pages, the pad columns become stepped faders for the respective track controls.

The User modes can be used for MIDI-assignable parameters in Live. User 1 is also suitable for Drum Racks, and User 2 for Max for Live presets, provided no custom assignments have been made. FL Studio can also use the controller as a clip launcher and to control notes and parameters; zones and Drum Racks are accessible via Performance mode.

The device is powered via USB and works as a class-compliant MIDI device without requiring driver installation. For mobile use with an iPad, you need an Apple Camera Connection Kit, which is not included. Please note: in Full Power mode, the controller only works with an iPad when connected to a separately powered USB hub. No additional power supply is required in normal Low Power mode.

The software bundle includes Ableton Live Launchpad Edition, the Novation Bass Station plug-in and a Loopmasters sample pack with over 1 GB of loops, drums and effects. Registration with Novation is required to access the software and content. The compact 240 mm housing fits on a studio desk and can be used for computer-based setups with Ableton Live, FL Studio or a compatible iPad app.

Features Novation Launchpad S

  • USB MIDI grid controller for triggering clips and controlling music software
  • 8×8 matrix with 64 multi-colour backlit pads
  • Session mode for launching clips and scenes, and navigating through live sets
  • Session Overview for displaying larger Ableton Live sets
  • Mixer mode with track volume, panning, Sends A and B, Stop, track activation, Solo and record arming
  • Volume, Pan and Send pages with pad columns acting as stepped faders
  • User 1 for Drum Racks and freely assignable MIDI parameters in Ableton Live
  • User 2 for Max for Live presets and freely assignable parameters
  • Support for FL Studio Performance mode, including zones and Drum Racks
  • MIDI class-compliant; no driver required for basic MIDI integration
  • USB bus-powered with Low Power and Full Power modes
  • iPad connection via Apple Camera Connection Kit; a separately powered USB hub is required in Full Power mode
  • Software bundle with Ableton Live Launchpad Edition, Novation Bass Station plug-in and Loopmasters sample pack
